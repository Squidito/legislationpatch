# Date Formatting & Shock-Quote Provenance

Restored verbatim from pre-slim CLAUDE.md (was lost in the 2026-07-06 slim; recovered same day). Includes James's 2026-06-29 decision: provenance is generated at render, never hand-edited into stored source strings.


- **Storage = ISO `YYYY-MM-DD`** for every date field (`date`, `stageDate`, `enactedDate`). This is the single canonical stored format; `validate-batch.js` ERRORs on any non-ISO date. `batch_processor.js` `formatDate()` emits ISO. ISO is required because the **mobile app's Hermes engine cannot parse human strings** like `"May 19, 2026"` (`new Date()` → Invalid), which silently scrambles bill ordering.
- **Display = `mm-dd-yy` (dashes)** everywhere, via `formatDateCompact()` in `app.js` and the matching `formatDate()` in `api.js` / `rep.js`. All three parse ISO directly from the string parts (no `new Date()` for ISO) to avoid the UTC→local off-by-one. On the app, `lib/format.ts` `parseDateParts`/`dateSortKey` are the Hermes-safe equivalents — use them, never `new Date(string)`, for bill dates.
- **`stageDate` = the latest action date** (most recent progress update), not the date the bill reached its stage — this is also the sort key. Keep it in sync with `bills_raw.json` `actionDate`.
- Shock quote card provenance is built ONE way for every quote type from util.js helpers. The **name-line context** is `quoteContext(q)` = **`"{Chamber} floor {debate|statement}"`** (no date); the **date** moved to the card **footer** to keep the line short. `debate` = the remark was made while a specific bill was on the floor (`q.billId` set; index footer shows the bill title, truncated, with the date pinned right via `.shock-quote-foot` / `.shock-quote-foot-date`); `statement` = a standalone floor remark (footer shows just the date — the old redundant "Floor Statement" text was dropped since the context line already says it). Chamber falls back to a plain "Floor" only when unresolved. Render sites: app.js carousel (context line + footer), floor.js carousel (context line + date-only footer), and the favorites card which has no footer so it uses the full one-line `quoteTagline(q)` (`"{context} · {mm-dd-yy}"`). Helpers `quoteChamber()` / `quoteDateCompact()` derive the parts (chamber: `q.chamber` field → "Rep."/"Sen." name prefix → "House/Senate Floor" source prefix; date: `q.quoteDate` ISO → parsed from `source`). **Don't hand-edit stored `source` strings for display** — these are generated at render. (Replaced the old "keep long format" rule + the interim `formatSourceLabel()`, per James 2026-06-29.)
  - **Footer layout (`.shock-quote-foot`):** pinned to the card bottom via `margin-top:auto` (so the empty space on a short card lands between the quote and the footer, not below it — the quote text is sized to content, NOT `flex:1`, for this reason). **Collapsed** = one row: bill title truncates (`flex:1`, ellipsis) with the date pinned right (`margin-left:auto`). **Expanded** = stacks to a column: the bill name gets full container width and wraps to the full title, and the date drops to its own row bottom-left (`margin-left:0`). Because `flex-direction` can't transition, the expand reflow is applied via 0.001s/0.5s-delay keyframes (`sq-foot-stack`, `sq-date-stack`, and `sq-bill-unwrap` which also sets `flex:none; width:100%`) on desktop `:has(:hover)`, and directly on mobile `:has(.sq-expanded)` — all matching the 0.5s dwell so the whole card reflows together.
